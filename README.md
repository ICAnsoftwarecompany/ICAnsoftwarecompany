## Engineering Approach

- **Arabic first:** full RTL layouts and Arabic / English interfaces with i18next and next-intl
- **Role-based apps:** separate dashboards and permissions per role
- **Realtime:** chat and notifications with Pusher and Laravel Echo
- **API driven:** clean service layers over REST APIs, with token authentication
- **Quality:** linting, automated tests and architecture checks on larger products
